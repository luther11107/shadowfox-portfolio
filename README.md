# Luther Graham | Developer Portfolio

Welcome to my personal developer portfolio! 

This project showcases my skills, projects, and learning journey as an aspiring full-stack developer, with interests in web development, data science, and machine learning.

🌐 **Live Website:** [luthergraham-portfolio.vercel.app](https://luthergraham-portfolio.vercel.app/)

## About the Project

This portfolio was built to introduce who I am, highlight my technical skills, showcase my projects, and provide an easy way to connect with me.

The website features a responsive layout, a personal introduction, project cards linking to GitHub repositories, and a contact form with client-side validation.

## Features

- **Home:** Introduction and links to my work.
- **About Me:** Background, interests, and development goals.
- **Skills:** Programming languages, web technologies, and tools.
- **Projects:** Selected projects with descriptions and GitHub links.
- **Contact Form:** Input validation and message submission.
- **Responsive Design:** Layout adapted for desktop and mobile screens.
- **Mobile Navigation:** Collapsible navigation menu for smaller screens.

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/luther11107/shadowfox-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd shadowfox-portfolio/shadowfox-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.
